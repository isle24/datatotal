# Agent Skill 查询与操作

`nas-traffic-lens` Skill 和 `ntl` / `ntl-sshbind` 支持查询 NAS 流量、系统、容器、告警，以及按明确指令新增、修改或删除单条流量监控和容器保护规则，或重启指定容器。操作命令需要 `--apply`；规则操作使用服务端 revision 防止基于过期数据覆盖，容器重启要求唯一 Docker ID。写接口要求配置面板密码并使用有效会话。

网页的规则分区保存也携带载入时的 revision：遇到冲突保留草稿，用户可选择重新加载。没有 revision 的旧客户端仍兼容旧接口，因此升级后应刷新旧页面。Agent 的请求超时、连接中断或异常响应会标记为结果未知，不自动重试。
