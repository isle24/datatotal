Traffic Lens 0.4.0 桌面预览版

- 控制台 UI 与交互改版：左侧固定导航、统一层级与间距、明暗主题，去掉装饰网格和渐变；手机端改为下拉切换页面。
- 设置按功能区（常用设置、流量告警、容器保护、通知渠道、AI 配置、维护与高级）独立保存。切换页面或保存其他分区不再丢失未保存的修改，保存失败会保留输入。
- 容器保护规则改为可搜索的容器单选/多选列表，支持全选当前结果、清除选择和已选摘要，不再手填容器名称或 ID；每个容器分别判断 CPU、内存和磁盘 I/O 阈值。
- 通知渠道明确“全部启用 / 指定渠道 / 不通知”三种模式；指定渠道但未选择时不再默认全部启用。
- 导航编辑器改用页面内确认，避免系统弹窗打断键盘操作；连接筛选、日期校验、空数据与无匹配状态更明确。
- 连接 NAS 后，容器保护达到阈值即重启该容器，重启次数不限，冷却结束后继续监控；每日上传告警按 Asia/Shanghai 零点计算（需要 NAS 服务端 2026.10.07-2 及以上）。
- 配套 NAS 镜像：`isle204/nas-traffic-lens:2026.10.07-3`，Docker Hub 同时提供 `linux/amd64` 与 `linux/arm64`。

下载：macOS Apple Silicon 用 arm64 DMG，Intel 用 x64 DMG，Windows 用 x64 setup.exe。

预览限制：Mac 为 ad-hoc 签名，尚未 Apple Developer ID 签名或公证；Windows 尚未 Authenticode 签名。遇到 No route to host 时应检查路由与系统本地网络权限。

本机暂未提供公网分类、进程网络流量、Docker 控制、GPU/NPU、温度和风扇采集；这些能力在连接 NAS 后使用 NAS 端采集结果。自动更新签名与 Apple/Windows 开发者签名彼此独立。
